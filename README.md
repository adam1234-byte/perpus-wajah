# PerpusDigital - Perpustakaan dengan Face Recognition

Aplikasi web perpustakaan (Flask + SQLite) dengan login dan peminjaman memakai pengenalan wajah.

## Cara menjalankan (Linux / WSL)
1. `git clone https://github.com/USERNAME/perpus-wajah.git`
2. `cd perpus-wajah`
3. `chmod +x setup.sh run.sh`
4. `./setup.sh`
5. `./run.sh`
6. Buka http://127.0.0.1:8000
